# Uso dell'AI nella fase backend

L'11 ottobre 2026 lo studente ha richiesto a Codex di implementare esclusivamente il backend Node.js/Express, dopo la pubblicazione delle specifiche iniziali. La richiesta includeva tre rotte GET/GET per ID/POST, array in memoria, validazione, middleware JSON e statico, errori HTTP, test, guida per principianti, commit distinti e push. Vietava frontend, database, TypeScript e funzionalità extra.

Questa è una sintesi del prompt, non una trascrizione integrale; il testo originale è nella conversazione dello studente con Codex. Codex ha letto le specifiche, generato il codice, i test e la documentazione e ha eseguito le verifiche indicate in `verifica-backend.md`. Non risultano modifiche manuali dello studente ai file in questa sessione. L'autorizzazione GitHub è stata fornita dallo studente.

La comprensione del codice e la preparazione all'esame restano attività dello studente. Non si dichiarano prove del frontend o attività manuali non svolte.
